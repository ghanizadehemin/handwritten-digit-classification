# Handwritten Digit Classification

A beginner machine learning project that classifies handwritten digits using Logistic Regression and the scikit-learn library.

## Project Overview

The goal of this project is to build a classification model that recognizes handwritten digits from numerical image features.

The project uses the built-in Digits dataset from scikit-learn.

## Technologies Used

- Python
- NumPy
- scikit-learn
- Matplotlib / Seaborn (for visualization, if used in the notebook)

## Model

Logistic Regression is used to classify the handwritten digits.

The dataset is split into training and testing sets to evaluate the model on unseen samples.

## Evaluation

The model is evaluated using:

- Accuracy
- Confusion Matrix

The notebook contains the implementation and evaluation results.

## How to Run

1. Download or clone this repository.
2. Open `TASHKHIS.ipynb` in Jupyter Notebook or JupyterLab.
3. Run the notebook cells in order.
